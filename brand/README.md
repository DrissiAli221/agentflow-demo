# Brand mark

- `agentflow-mark.svg`: the full approved silhouette for larger placements.
- `agentflow-mark-small.svg`: a rounder silhouette with a wider opening for 16–32 px slots. Used by the rail, login page and favicon.

Both are standalone vector paths in solid coral `#E0603F`, with transparent backgrounds. Keep the opening intact when sizing the mark. The interface wordmark uses the existing Switzer family at weight 600 and `-0.025em` tracking; it remains readable text alongside the decorative image.
